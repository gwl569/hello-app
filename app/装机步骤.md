# 免费把 Hello 装到 iPhone（不用开发者账号、不用 Mac）

## 一、准备（电脑上，一次性）

1. **iTunes**：从 Apple 官网下 Windows 版安装（**不要用微软商店版**，AltServer 认不出来）。
2. **AltServer**：从 altstore.io 下载 Windows 版，双击运行，托盘里会出现小图标。
3. 用数据线把 iPhone 连上电脑，手机上点「信任此电脑」。

## 二、让云端构建出安装包（免费，不需要 Mac）

1. 在 GitHub 新建一个**公开仓库**（比如 `hello-app`）。
2. 把 `D:\codex的制作内容\Hello\app` 这个文件夹里的**全部文件**上传上去（网页上「Add file → Upload files」拖进去即可）。
3. 上传后点仓库顶部的 **Actions** → 左侧 **Build iOS (unsigned ipa)** → 右侧 **Run workflow**。
4. 等 10~15 分钟跑完，页面底部 **Artifacts** 里下载 `Hello-unsigned-ipa`，解压得到 `Hello-unsigned.ipa`。

## 三、装到手机（免费 Apple ID）

1. 电脑托盘点 AltServer 图标 → **Install AltStore** → 选你的 iPhone。
2. 会提示输入 Apple ID（用你平时登录 App Store 的那个，**不需要付费开发者账号**）。
3. 手机上：设置 → 通用 → VPN与设备管理 → 信任你的 Apple ID 证书。
4. 手机上：设置 → 隐私与安全性 → **开发者模式** → 打开 → 重启手机。
5. 打开手机上的 **AltStore** → 「+」→ 选电脑上的 `Hello-unsigned.ipa` → 安装。
6. 回到桌面就有 Hello 图标了，打开 → 允许通知 → 建提醒即可（**锁屏准点响，不依赖网络**）。

## 四、每 7 天续签（免费签名的唯一代价）

- 保持 **AltServer 在电脑上运行**，手机和电脑连**同一个 Wi-Fi**；
- AltStore 会自动在后台续签；也可以打开 AltStore 手动点 **Refresh All**；
- 如果超过 7 天没续签，App 会打不开，重新刷新一次即可，数据不会丢。

## 五、以后要更新 App

改完代码把文件重新传到同一个 GitHub 仓库 → Actions 再跑一次 → 下载新的 ipa → AltStore 里安装覆盖即可。
